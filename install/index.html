SubsPair

AI 驱动的 YouTube 双语字幕生成器，iPhone、iPad 上 App 和网页版通用

请在装了小火箭的 iPhone 或 iPad 上，用 Safari 打开这个页面。

先做好这两件事

  1. 小火箭首页的「全局路由」选「配置」。
  2. 在小火箭里打开 HTTPS 解密并安装证书，再到 iPhone 的「设置」里把证书装上，最后在「设置 → 通用 → 关于本机 → 证书信任设置」里打开「完全信任」。步骤见 安装说明第一步。

以前给别的模块做过的，可以跳过。装的时候小火箭如果提示「No PKCS12 Certificates」（意思是还没有可用的证书），说明第二件事没做完：做完后在小火箭里把模块删掉，再点下面的按钮重装。

一键安装到小火箭

点了之后 Safari 会问要不要打开小火箭，点「打开」，再按提示添加模块。

按钮没反应？

复制下面的地址，在小火箭「配置 → 模块」点右上角「+」粘贴。

https://raw.githubusercontent.com/kaixuedev/SubsPair/release/SubsPair.sgmodule

装好之后

用 Safari 打开 https://subs.test/ 填 DeepSeek 密钥，步骤见 安装说明第三步。然后打开英文视频，字幕选英文（不要选「自动翻译」）。

填好后，你看的视频的字幕全文会发给你选择的模型服务商，对方能看到并可能留存，详见 隐私说明。

SubsPair 只在你的手机上运行，只处理 YouTube 字幕的读取与显示；翻译由你自己选择并开通的模型服务商完成，本项目不提供模型服务，不提供任何网络接入服务，不含服务器配置；开发者不运营服务器、不收集数据、不收费。

本项目与 YouTube、Shadowrocket、DeepSeek 均无关联；请在所在地法律法规允许的范围内使用，并遵守相关服务的条款。
